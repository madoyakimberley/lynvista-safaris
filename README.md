# Lynvista Safaris

A modern tourism and travel booking platform built for **Lynvista Safaris Limited**, showcasing safari packages, travel experiences, destinations, and customer booking services.

 **Live Website:** https://lynvistasafaris.com

**GitHub Repository:** https://github.com/madoyakimberley/lynvista-safaris

---

## Overview

Lynvista Safaris is a travel and tourism company dedicated to providing unforgettable safari experiences across Kenya and East Africa. This website serves as the company's digital presence, allowing customers to explore destinations, view tour packages, make inquiries, and connect with the Lynvista team.

## Installation

Clone the repository:

```bash
git clone https://github.com/madoyakimberley/lynvista-safaris.git
```

Navigate into the project:

```bash
cd lynvista-safaris
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```
